# Deployment Instructions

## Netlify Deployment Steps:

1. Go to https://netlify.com
2. Click "Sign up" (use GitHub/Google account for easy setup)
3. Choose "Drag and drop your site output folder here"

## Files to Upload:
- Upload the entire "WS Web" folder
- Make sure all subfolders are included
- Exclude: node_modules, .git, .env files

## After Upload:
- You'll get a live URL like: random-name-123456.netlify.app
- Test your site immediately
- Can change site name later in settings

## Custom Domain (Optional):
1. Go to Site settings → Domain management
2. Add your custom domain
3. Update DNS records as instructed
